# BotFarm — онлайн-запись для малого бизнеса в одном Telegram-боте

> Агенту и разработчику: сначала прочитай [AGENTS.md](AGENTS.md) — там устройство, подводные камни и план работ.

Один бот и одно Mini App обслуживают сколько угодно бизнесов. Клиент открывает ссылку
мастера (`t.me/<бот>?start=<slug>`) и видит только его: услуги, цены, портфолио, запись, свои записи.

- **Клиент:** запись в 3–4 касания, отмена, напоминания в чат.
- **Владелец/админ бизнеса:** записи по дням, услуги, график с перерывами, выходные и отпуск,
  мастера, портфолио, клиенты, рассылка, помощники, ссылка и QR.
- **Суперадмины** (`SUPERADMIN_IDS`): все бизнесы, создание из шаблона с готовым текстом
  для холодной рассылки и ссылкой-приглашением владельца, блокировка.

Шаблоны: бьюти-мастер, барбершоп, репетитор/психолог, массаж/тренер, авто (`server/templates.ts`).
Дизайн и решения — `docs/design.md`.

## Стек и бесплатный хостинг
Vercel Hobby (Mini App + одна функция `api/index.ts`) и Supabase Free (Postgres).
Защита от двойной записи — ограничение `bookings_no_overlap` в базе. Фото портфолио хранятся в Telegram.

## Структура
```
api/index.ts       единственная функция: /api/rpc, /api/bot, /api/cron, /api/photo, /api/setup, /api/health
server/            логика (слоты, записи, права, бот, уведомления, напоминания, шаблоны)
web/               Mini App (React)
db/001_init.sql    схема — выполнить в Supabase SQL Editor
db/002_pg_cron.sql необязательно: напоминания каждые 15 минут
tests/             vitest на встроенном Postgres (PGlite)
dev/local-server.ts локальный запуск без Telegram и Supabase
```

## Локально
```
npm install
npm test
npm run build && npm run local   # http://localhost:8787/?devUser=1 (1 — суперадмин, 2 — владелец, 3+ — клиенты)
```

## Деплой
1. Supabase: новый проект → SQL Editor → выполнить `db/001_init.sql`.
2. Vercel: импорт проекта, переменные из `.env.example`.
3. Открыть `https://<проект>.vercel.app/api/setup?key=<CRON_SECRET>` — бот получит вебхук, команды и кнопку меню.
4. По желанию: BotFather → `/newapp` → URL сайта, имя записать в `BOT_APP_NAME`; выполнить `db/002_pg_cron.sql`.
