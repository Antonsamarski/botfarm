# BotFarm — один Telegram-бот + Mini App для множества малых бизнесов

## Зачем
Антон и его друг собирают «ферму ботов» для мини-предпринимателей (мастера, барберы,
репетиторы, автосервисы), которых находят холодной рассылкой. Для предпринимателя сервис
бесплатный, поэтому и инфраструктура должна стоить 0 ₽ и стабильно держать до ~1000 пользователей.
Основа — рабочий бот записи к мастеру маникюра (`bot/`, aiogram + SQLite): его логику
переносим и исправляем слабые места.

## Что считается успехом
- Клиент открыл ссылку мастера → видит **только этот бизнес**: услуги, цены, портфолио, запись, свои записи.
- Предприниматель управляет всем сам с телефона: услуги, мастера, график, выходные, записи, рассылка, админы.
- Владельцы платформы (суперадмины) видят все бизнесы, создают их из шаблона за минуту,
  отправляют ссылку-приглашение владельцу, блокируют/разблокируют.
- Двойная запись на одно время невозможна даже при одновременных нажатиях.
- Ноль платных сервисов.

## Анти-цели (v1)
Онлайн-оплата, маркетплейс/каталог всех бизнесов, отдельный бот на каждый бизнес,
корзина товаров. Клиенты не видят чужие бизнесы.

## Роли
| Роль | Кто | Что видит |
|---|---|---|
| Суперадмин | Telegram ID из `SUPERADMIN_IDS` (Антон + друг) | все бизнесы, создание из шаблонов, блокировка, общая статистика, вход в любой бизнес как админ |
| Админ бизнеса | владелец (owner) и его помощники (admin) | панель своего бизнеса |
| Клиент | любой пользователь Telegram | только бизнес, по ссылке которого пришёл |

## Как человек попадает в нужный бизнес
- Ссылка бизнеса: `https://t.me/<бот>?start=<slug>` (работает всегда) или, если в BotFather
  создано Mini App, `https://t.me/<бот>/<app>?startapp=<slug>` — сразу открывает приложение.
- Бот запоминает последний бизнес пользователя и ставит ему личную кнопку меню, которая
  открывает Mini App этого бизнеса. Повторный `/start` без параметра — снова тот же бизнес.
- Без ссылки и без истории пользователь видит экран платформы «Подключить свой бизнес».
- Приглашение админа: `?start=inv_<код>` — одноразовый код, делает человека владельцем/админом.

## Онбординг предпринимателей (под холодную рассылку)
1. **Демо заранее:** суперадмин создаёт бизнес из шаблона с названием мастера → получает
   ссылку-приглашение и ссылку для клиентов → отправляет в рассылке «ваш бот уже готов, нажмите».
2. **Самостоятельно:** человек жмёт «Подключить свой бизнес», выбирает шаблон и пишет название —
   бизнес создаётся сразу, суперадмины получают уведомление и могут заблокировать.

## 5 шаблонов (по анализу рынка услуг в Telegram)
Самые массовые пользователи записи в Telegram — частные мастера сферы услуг, у которых записи
теряются в переписках, а клиенты забывают о визитах. Шаблон = набор стартовых данных
(услуги с длительностью и ценой, график, тексты, поля анкеты, термины), всё правится в админке.
1. **Бьюти-мастер** (маникюр, брови, ресницы) — один мастер, услуги 30–180 мин, портфолио, напоминания.
2. **Барбершоп / парикмахер** — несколько мастеров, выбор мастера или «любой свободный».
3. **Репетитор / психолог / консультант** — занятия онлайн или офлайн, поле «класс/цель», ссылка на созвон.
4. **Массаж / тренер / SPA** — сеансы 60/90 мин, поле «пожелания».
5. **Авто** (детейлинг, шиномонтаж, автосервис) — поле «марка, модель, госномер», длинные слоты.

## Архитектура (решение Claude: самый простой бесплатный и стабильный вариант)
- **Vercel Hobby (бесплатно):** статический Mini App (Vite + React) + 3 serverless-функции:
  `api/bot` (вебхук бота, grammY), `api/rpc` (всё API Mini App), `api/cron` (напоминания).
  Сервера нет — нечему «падать», масштабирование автоматическое.
- **Supabase Free (бесплатно):** Postgres через пулер (transaction mode), драйвер `postgres`.
  Защита от двойной записи — ограничение-исключение `btree_gist` на пересечение интервалов.
- **Фото портфолио хранятся в самом Telegram** (бот отправляет фото админу и сохраняет file_id),
  отдаются через `api/rpc` с CDN-кэшем Vercel. Хранилище бесплатно и не тратит 1 ГБ Supabase.
- **Авторизация Mini App:** проверка подписи `initData` (HMAC от токена бота) на каждом запросе.
- **Напоминания:** Vercel Cron на Hobby — раз в сутки (вечером: «завтра в 14:00»). Опционально
  `pg_cron` в Supabase дёргает `api/cron` каждые 15 минут → напоминание за 24 ч и за 2 ч.
  Ежедневный cron заодно не даёт бесплатному Supabase уснуть (он паузится после 7 дней тишины).
- **Домен:** оставляем `*.vercel.app` — по отзывам он открывается из РФ, а свои домены на IP Vercel
  иногда блокируются.

## Что исправляем относительно старого бота
- Не предлагались прошедшие слоты на сегодня → теперь учитываются время, часовой пояс бизнеса и
  минимальный запас до записи.
- Двойная запись при одновременном подтверждении → ограничение в БД.
- Услуги без длительности (всё по 60 мин) → длительность у каждой услуги, слоты считаются под неё.
- Состояние диалога терялось при перезапуске → весь сценарий записи в Mini App, бот без состояния.
- Markdown ломался на именах с `_`/`*` → HTML с экранированием.
- Клиент не узнавал об отмене админом → уведомление клиенту.
- Время сервера вместо времени бизнеса → часовой пояс в настройках бизнеса.

## Лимиты бесплатных тарифов (запас под 1000 пользователей)
Vercel Hobby: ~1 млн вызовов функций/мес, 100 ГБ трафика. Supabase Free: 500 МБ БД, пулер.
1000 пользователей × ~50 запросов/мес ≈ 50 тыс. вызовов — запас в десятки раз.
Нюанс: правила Vercel Hobby рассчитаны на некоммерческое использование; пока сервис бесплатный —
нормально, при монетизации стоит перейти на Pro или VPS.
